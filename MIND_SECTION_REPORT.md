# Mind Section Assessment Report
## Bloom° Holistic Assessment Tool

**Purpose:** Complete reference of all Mind category quizzes, questions, answers, and evaluation criteria.

---

## Overview

The **Mind** category assesses cognitive abilities across 4 subcategories with **13 total quizzes**:

| Subcategory | Quizzes | Grades |
|-------------|---------|--------|
| Attention/Memory | 6 | 1-8 |
| Learning Style | 1 | 1-8 |
| Critical Thinking | 2 | 1-4 |

| Score | Level | Color |
|-------|-------|-------|
| 90-100% | Excellent | Green |

## 1.1 Attention Questionnaire
**Based on:** Attentional Control Scale for Children (ACS-C)

### Focusing Questions (9 items)
*Rating: 1=Never, 2=Sometimes, 3=Often, 4=Always*

| # | Question | Reverse |
|---|----------|---------|
| 1 | It's hard for me to focus on schoolwork when the classroom is noisy | No |
| 2 | When I'm doing hard math problems, it's difficult for me to focus | No |

| 8 | It's hard for me to focus when I'm excited about something | No |
| 11 | When I start something new, it takes me time to really get into it | No |
| 12 | It's hard for me to listen to the teacher and take notes at the same time | No |
| 20 | It's hard for me to think about things in a different way once I have an idea | No |

### Shifting Questions (6 items)

| # | Question | Reverse |
|---|----------|---------|
| 10 | I can easily stop what I'm doing and switch to something else | Yes |
| 13 | I can quickly get interested in new things when I need to | Yes |
| 14 | I can easily do homework while talking to someone | Yes |

| 19 | I can easily switch between doing different activities | Yes |

### Scoring
- Non-reversed: use value (1-4)
- Reversed: use (5 - value)
- **Focusing Level:** Average ≥3.0 = Good, 2.0-2.9 = Fair, <2.0 = Needs Support
- **Shifting Level:** Same scale

### Report Contribution
Provides separate Focusing and Shifting scores with interpretations and recommendations.

# 2. LEARNING STYLE

## 2.1 Learning Styles Quiz (VARK)

**Identifies:** Visual, Auditory, Reading/Writing, or Kinesthetic preference

### Questions & Answers

| # | Question | Visual | Auditory | R/W | Kinesthetic |
|---|----------|--------|----------|-----|-------------|
| 1 | When learning something new, I prefer to: | Watch video/pictures | Listen to explanation | Read about it | Try it myself |
| 2 | When I need to remember something, I: | Picture it in mind | Say it out loud | Read/re-read it | Write it/act it out |
| 3 | In class, I learn best when: | Diagrams and charts | Teacher talks/discusses | Read textbooks | Hands-on activities |
| 4 | When I get lost, I prefer to: | Look at a map | Ask for directions | Look up online | Explore/instincts |
| 5 | When telling a story, I: | Describe how things looked | Use voices/sounds | Focus on details/facts | Act out with hands |

### Scoring
Count responses per style. Highest count = **Dominant Style**.

### Report Output
Shows learner type (e.g., "Visual Learner") instead of percentage, with style-specific recommendations.

# 3. CRITICAL THINKING

## 3.1 Analogy Quiz (Grades 1-4)

### Grade 1

| Question | Answer | Explanation |
|----------|--------|-------------|
| If cats meow, then dogs ___ | bark | Dogs bark like cats meow |
| If the sun is hot, ice is ___ | cold | Opposites |
| If a bird has wings, a fish has ___ | fins | Both used for movement |
| If people walk, cars ___ | drive | Both are locomotion |
| If rain is wet, fire is ___ | hot | Different properties |

### Grade 2

| Question | Answer | Explanation |
|----------|--------|-------------|
| Day is to sun as night is to ___ | moon | Both light sources for their time |
| Pen is to write as brush is to ___ | paint | Tool-to-action relationship |
| Cow is to milk as hen is to ___ | egg | Animal-to-product relationship |
| Eyes are to see as ears are to ___ | hear | Body part-to-function |
| Kitchen is to cook as bedroom is to ___ | sleep | Room-to-activity |

### Grade 3

| Question | Answer | Explanation |
|----------|--------|-------------|
| Sam > Jane > Ben in height. Who's shortest? | Ben | Transitive reasoning |
| If winter is cold, summer is ___ | hot | Seasonal opposites |
| If teacher teaches, doctor ___ | heals | Profession-to-action |
| Morning is to breakfast as evening is to ___ | dinner | Time-to-meal |
| Library is to books as museum is to ___ | art | Place-to-contents |

### Grade 4

| Question | Answer | Explanation |
|----------|--------|-------------|
| Seed is to plant as egg is to ___ | bird | Beginning-to-grown |
| Foot is to shoe as hand is to ___ | glove | Body part-to-covering |
| Book is to read as guitar is to ___ | play | Object-to-action |
| Captain is to ship as pilot is to ___ | airplane | Operator-to-vehicle |
| Author is to book as composer is to ___ | music | Creator-to-creation |

**Scoring:** 1 point per correct answer. 5 questions per grade.

# REPORT GENERATION

## How Scores Contribute to Report

1. **Individual Quiz Scores** → Percentage and performance level
2. **Subcategory Averages** → Combined score for Attention, Memory, etc.
3. **Overall Mind Score** → Average of all completed quizzes
4. **Learning Style** → Shows learner type, not percentage

## Performance Interpretations

| Area | ≥90% | 75-89% | 60-74% | <60% |
|------|------|--------|--------|------|
| Attention | Excellent focus | Good, minor gaps | Developing | Needs support |
| Memory | Strong recall | Solid skills | Developing | Practice needed |
| Critical Thinking | Excels at reasoning | Can reason well | Encourage step-by-step | Games/puzzles help |
| Perception | Excellent visual skills | Good with growth areas | Pattern activities help | Drawing/puzzles help |

## Key Recommendations by Score

**Below 75%:**
- Attention: Mindfulness, quiet environment, break tasks down
- Memory: Daily exercises, grouping strategies, memory games
- Critical Thinking: Ask "why" questions, puzzles, strategy games
- Perception: Spot-the-difference, jigsaw puzzles, drawing
